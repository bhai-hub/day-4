# day-4: L'ANATOMIE &bull; Haute Joaillerie

A modern luxury haute joaillerie web experience inspired by human anatomy, physiological systems, and fine jewelry.

## Key Features
- **4 Anatomical Frames & Color Dissolve:**
  - **Frame 1: Nerves &bull; Champagne Gold & Antique Bronze:** Full-bleed fluted rippled glass with model portrait, ambient amber illumination, and real-time running water simulation.
  - **Frame 2: Arteries &bull; Oxblood Red:** Floating ruby suite across three perspective angles in open space.
  - **Frame 3: Veins &bull; Prussian Blue:** Royal sapphire signet suite.
  - **Frame 4: Bones &bull; Bone White & Alabaster:** Physician natural pearl drop suite.
- **Interactive Pulse:** Heartbeat pulse ripples radiating on cursor interaction and hover.
- **Dedicated Product Dossier:** Fluid transition to high-jewelry showcase with multi-angle inspector, specifications, and shopping bag drawer.
- **Minimalist Luxury Design:** Editorial typography (`Cinzel`, `Cormorant Garamond`, `Pinyon Script`), responsive layouts, and smooth animations.

## Tech Stack
- HTML5 Canvas
- Modern CSS (Custom properties, grid, flexbox, glassmorphism)
- Vanilla JavaScript (ES6+)
- Node.js local preview server
